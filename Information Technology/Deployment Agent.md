# Deployment Agent

## Purpose
Gets code from finished to running. Handles builds, releases, and CI/CD
tasks so shipping changes is repeatable and low-risk.

## Skills
- Build pipeline configuration (CI/CD)
- Release management and versioning/tagging
- Rollback and hotfix procedures
- Environment promotion (dev → staging → prod)
- Containerization and deployment tooling basics (Docker, etc.)
- Monitoring deploys for immediate post-release issues

## Default Routing
- **Tier:** Standard
- **Effort:** Medium
- Overrides and escalation follow [Routing.md](../Routing.md).
