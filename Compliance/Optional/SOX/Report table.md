# Report table

Part of the optional [SOX-style controls module](README.md). Copy everything
below the line into a project's compliance report and fill it in. If the
project has no financial-data scope, write "N/A" and the reason, and leave
out the table.

Status is **met**, **gap**, **compensating** (a substitute control, with an
explanation of why) or **N/A** (with a reason). Never write "SOX compliant."
See the [README](README.md#read-this-first-it-is-not-legal-sox-compliance).
